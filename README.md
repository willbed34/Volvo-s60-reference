# Volvo S60 Reference

An unofficial, owner-focused reference for the 2021 Volvo S60 T5 Inscription.

The site is being built as a straightforward, searchable owner's reference: vehicle overview, controls, maintenance, DIY repairs, troubleshooting, and technical information.

## Scope and accuracy

This project focuses on the 2021 S60 T5 Inscription. Equipment and specifications can vary by market, build date, and options. Confirm vehicle-specific service procedures, fluid specifications, torque values, part numbers, and safety-critical information against Volvo documentation and the vehicle's VIN.

## Development

The site is built with Astro and plain CSS. Run `npm install` and `npm run dev` to start the local development server.
